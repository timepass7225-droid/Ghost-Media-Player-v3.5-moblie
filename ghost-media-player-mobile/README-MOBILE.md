# Ghost Media Player — Mobile edition (Android)

Phone version of Ghost Media Player v3.5. Same features (DJ Mode, Radio, Lyrics, Effects, Themes), but a phone layout and lighter rendering. The desktop project is untouched.

## What is different from desktop
- Bottom tab bar: Library / Radio / DJ / Lyrics / More (Effects, Themes, Settings, About). Library, Effects, Themes, Settings open as a full-width sheet.
- Big touch targets (44px+), seek bar on top, hardware buttons control volume (slider hidden, Boost pill kept).
- Lite rendering: frosted-glass blur disabled, 3D look and orb menu off on first launch (can be turned on again in Settings).
- Android back button: closes sheet / screen first, then minimises the app so music keeps playing.
- Lock-screen / notification controls (Media Session), screen stays on only while a video plays.
- Electron, ffmpeg-static and desktop-only files removed; JS/CSS minified (about 33% smaller).

## Build the APK
```
npm install
npm run cap:add:android     # once
npm run cap:build:debug     # -> android/app/build/outputs/apk/debug/app-debug.apk
```
`www-src/` is the readable source, `www/` is generated by `npm run build`. Edit www-src, never www.

## Test (headless Chromium, phone sizes)
`npm test` (needs Python playwright). Checks playback, tabs, overflow, touch sizes, back button, video, 4x slower CPU.

## Not verified here
The APK itself was not built or run on a real phone (no Android SDK in my sandbox). Playing music with the screen locked may need a background-audio Capacitor plugin on some phones; test on a real device.
